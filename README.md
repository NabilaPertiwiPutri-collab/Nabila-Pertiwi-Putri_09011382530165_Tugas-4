Analisis root:x:0:: :
- root : nama grup
- x : bagian password grup (biasanya tidak menyimpan password langsung disini)
- 0 : Group ID (GID)
- Bagian setelah 0 : daftar anggota grup, jika ada
Jadi, grup root memiliki GID 0. Grup ini merupakan grup khusus dengan hak ases tertinggi pada Sistem Linux.
